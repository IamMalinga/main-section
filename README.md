# 🌍 Trip & Travel Planning Web Platform

An all-in-one travel planning web application designed for travelers in Sri Lanka. This platform allows users to plan personalized trips, get AI-generated recommendations, book services like vehicles and travel guides, and communicate with other travelers — all in one place.

## 🚀 Features

### ✈️ Trip Planning
- Create and manage trips with:
  - Destinations
  - Travel duration
  - Number of travelers
  - Budget preferences (Cheap / Moderate / Luxury)

### 🧠 Smart Recommendations
- AI-powered suggestions for:
  - Hotels & Restaurants (via Gemini & Google Places APIs)
  - Daily itinerary and attractions
- Route optimization using Google Distance Matrix API

### 🔐 Secure Authentication
- JWT-based session management
- Email verification via Brevo SMTP API
- Password hashing with bcrypt
- Forgot password and resend verification features

### 📊 User Dashboard
- View active and past trips
- Visualized routes on maps
- Notifications and reminders
- Service usage history tracking

### 💬 Integrated Services
- Vehicle rentals and availability
- Travel guide booking with filters (e.g., language, rating)
- Real-time chat with travelers using Socket.IO
- Dining and event recommendations based on location

## 🛠️ Tech Stack

### Frontend
- React.js with Context API
- Material-UI for design components
- Framer Motion and Parallax for animations

### Backend
- Node.js with Express
- MongoDB & Mongoose
- Firebase (for profile pictures and media)
- Socket.IO (for chat system)

### APIs & Tools
- Google Maps APIs (Distance Matrix, Autocomplete, Geolocation)
- Gemini API (AI-based recommendations)
- Brevo SMTP (Email verification)
- Jest (Unit testing)
- Figma, Photoshop, Lucidchart (Design and architecture diagrams)
